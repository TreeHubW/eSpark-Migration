# Grid Availability Loss [MWh]

**Units:** MWh  |  **Excel column:** AS  |  **Kind:** site-data pull  |  **Group:** Grid Availability

Energy lost to grid unavailability / economic curtailment on the day, stored as a negative number.

## How it gets its value

Computed by [[Formula - Grid Availability Loss (MWh)]].

> [!warning] The sign flip means a curtailment of 5 MWh shows as -5.
