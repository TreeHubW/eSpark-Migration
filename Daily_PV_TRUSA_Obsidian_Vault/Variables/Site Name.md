# Site Name

**Units:** text  |  **Excel column:** C  |  **Kind:** input  |  **Group:** Identity & Calendar

Plant name. Together with Month it is the key every monthly lookup uses, and it selects which site data sheet is read for the daily pulls.

## How it gets its value

Typed in by hand. There is no formula in this column.
